# Changelog

Release notes are maintained by [Changesets](https://changesets.github.io) per
package. Each `packages/*` directory keeps its own authoritative changelog:

- [`@thexjs/core`](packages/core/CHANGELOG.md)
- [`@thexjs/auth`](packages/auth/CHANGELOG.md)
- [`@thexjs/env`](packages/env/CHANGELOG.md)
- [`@thexjs/cli`](packages/cli/CHANGELOG.md)
- [`@thexjs/hooks`](packages/hooks/CHANGELOG.md)
- [`@thexjs/adapter-vercel`](packages/adapter-vercel/CHANGELOG.md)
- [`create-thexjs-app`](packages/create-thexjs-app/CHANGELOG.md)

Versioning policy and support windows live in
[`VERSIONING.md`](VERSIONING.md) and [`SUPPORT.md`](SUPPORT.md). Changes before
the per-package changelogs existed live in the git history.
